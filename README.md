Portfolio personnel réalisé en **HTML / CSS / JavaScript / PHP**.

## Pages du site
- Accueil
- Projets
- Compétences
- Contact

## Architecture des dossiers

```text
PortfolioSLAMOral/
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── img/
│   └── js/
│       └── main.js
├── data/
│   └── messages.txt
├── includes/
│   ├── footer.php
│   └── header.php
├── competences.php
├── contact.php
├── index.php
├── projets.php
└── README.md
```

## Lancer le projet en local

```bash
php -S 0.0.0.0:8000
```

Puis ouvrir `http://localhost:8000`.
